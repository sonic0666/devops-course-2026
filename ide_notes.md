# Git: IDE vs CLI

## Что удобно в VS Code
1. Наглядная визуализация diff — сразу видно, какие строки изменены, без чтения текстового вывода.
2. Коммит через UI: ввёл сообщение, нажал галочку — быстрее, чем печатать команды.
3. Встроенный редактор конфликтов слияния показывает оба варианта и позволяет выбрать нужный в один клик.

## Что удобнее делать в терминале
1. Скриптуемые и специфичные операции (interactive rebase, cherry-pick, работа с несколькими remote) — в терминале это быстрее и работает одинаково на любом сервере, включая продакшен без GUI.
